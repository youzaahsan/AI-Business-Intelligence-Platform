# Changelog

All notable changes to the AgentBI platform are documented here.

## [1.0.0] - 2026-10-04

### Added
- **Multi-Agent Orchestration**: Deployed 10 specialized autonomous agents (Supervisor, Research, Document, Data Analyst, BI, Forecast, Segmentation, Anomaly, Fact Checker, Report Agent).
- **Interactive Full-Stack Web Application**: React 19 + Express server with automated data profiling, interactive charts, and PDF/Excel export.
- **RAG Document Engine**: Semantic chunking, vector store abstraction (ChromaDB/Qdrant), and grounded source citations.
- **ML Analytics Engine**: Linear regression, Holt-Winters exponential smoothing, RFM customer clustering, and Z-score anomaly detection.
- **Enterprise Security**: Role-based access control (Admin, Manager, Analyst, User), password hashing, and structured audit logs.
- **Full Architecture Documentation**: 20 comprehensive technical guides in `docs/`.
